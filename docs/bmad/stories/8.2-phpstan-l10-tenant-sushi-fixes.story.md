## Summary

Risolti 81 errori PHPStan L10 nel modulo Tenant, principalmente nel trait `SushiToJson` e nelle sue implementazioni.

## Root Causes & Solutions

### 1. SushiToJson.php (trait) — 35+ errors
- **Missing return types**: `getSchema()`, `getSushiRows()`, `sushiShouldCache()`
- **Array without generics**: `loadExistingData()` returned `array` not `array<string, mixed>`
- **json_decode/encode safety**: Using `Safe\json_decode` / `Safe\json_encode`
- **Type narrowing**: Added `Assert::isArray()` + `/** @var */` for json_decode results
- **getRows() return type**: Added `array_values()` to ensure `array<int, ...>` not `array<int|string, ...>`
- **Intersection type callbacks**: Added `Assert::isInstanceOf(Model::class)` + `/** @var Model&HasSushiToJson */` in bootSushiToJson()

### 2. TestSushiModel.php — 12 errors
- Same fixes as trait (inherited)
- Added `Safe\json_decode` / `Safe\json_encode` imports
- Type-narrowed `loadExistingData()` return type

### 3. Delete/UpdateJsonFileByRecordAction.php — 8 errors
- Type-narrowed `Arr::keyBy()` result with `/** @var array<int|string, array<string, mixed>> */`
- Fixed type narrowing after `Arr::forget()` with inline @var comment

### 4. EnsureKeysAction.php (Xot module) — Critical fix
- **Fixed phpdoc parameter order bug**: Was backwards (`@param array<int|string, string|int> $keys` on first param, should be on second)
- Relaxed parameter type to `array<int|string, array<string, mixed>|mixed>` for better compatibility

### 5. SushiConnectionByNameTest.php — 1 error
- Changed `$model::resolveConnection()` to `$model->resolveConnection()`
- Added `Assert::isInstanceOf($model, Model::class)` for type narrowing
