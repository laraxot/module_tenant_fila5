# Manuale utente Tenant

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Tenant delimita contesto, dominio, configurazione e isolamento dei dati.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente normale/gruppo | Opera solo nel tenant corrente. |
| Tenant admin/owner | Gestisce il proprio tenant nel perimetro autorizzato. |
| Admin/super-admin | Governa tenant, domini e configurazione globale secondo policy. |

Non cambiare tenant per aggirare una policy.
